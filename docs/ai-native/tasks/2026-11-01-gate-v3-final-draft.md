## 1. Aggregation of components into a gate verdict (all gates)
Each gate is a list of **components**. A component is PASS, FAIL, NOT_EVALUABLE, or NOT_APPLICABLE (recorded with its reason and excluded; never counted as a pass).
`gate = FAIL if any evaluable component FAILS; else NOT_EVALUABLE if any applicable component is NOT_EVALUABLE; else PASS` ⇒ **FAIL always outranks NOT_EVALUABLE**; a gate whose only applicable components pass is PASS even if some components are NOT_APPLICABLE. Tested (4 aggregation tests).

## 3. G7 — object orientation (requires data contract v2 quaternions)
**Geometry** (`geometry_v2.py`, conventions verified against MuJoCo): q = (w,x,y,z); R = xmat (body→world); Euler yaw = atan2(R10, R00) = heading of the body-x axis on the horizontal plane, **undefined when the body-x axis is vertical**; hnorm = √(R00² + R10²); the box is a cuboid so poses are invariant under body-side 180° rotations about x, y, z (group D2); geodesic distance is taken modulo D2; tilt = arccos(R22), sym-tilt = min(tilt, π − tilt).
**Regimes** (fixed rules on the TRUE trajectory q_t … q_{t+K}; independent of predictions; diagnostic stratification, never an inference-time selection; precedence singular > tumbling > rotating > stable):
singular: min hnorm < 0.20 · tumbling: not singular and some per-step symmetric geodesic > 0.30 rad · rotating: neither and total symmetric geodesic over the horizon ≥ 0.02 rad · stable: otherwise.
Evidence for the scales (replay of 394 episodes; `validation.json`): all 98 singular events have hnorm_min ≤ 0.13; physical fast rotations have median per-step symmetric geodesic 1.30 rad and 102 of 62 918 steps in non-event episodes exceed 0.30 rad (0.16 %); regime mix in the 360 non-event sampled episodes: stable 56 %, rotating 41 %, tumbling 2.4 %, singular 0 % (event episodes over-sampled in the full sample: singular 3.1 %, tumbling 3.0 %).
**Components** (K = 20 gating; horizons 1/5/10/20 reported):
1. Yaw non-inferiority on heading-valid (stable + rotating) active windows, wrap-aware error e = |wrap(ŷaw − yaw)| from composed quaternions: R = E_model / max(E_best, 1e-4), E_best = min(E_persistence, E_ridge); **R ≤ 1.10** and group-bootstrap **upper bound ≤ 1.25**.
2. Static hallucination on the INPUT-only subset S_in (speed ≤ 0.005 m/s, no finger contact, palm force ≤ 0.01 N in all history rows, candidate gripper stays open), heading-valid windows: (a) mean e_20 ≤ **0.01 rad**; (b) group-bootstrap upper bound of (E_model − E_persistence) ≤ **0.01 rad**; (c) relative E_model / max(E_persistence, **0.003**) ≤ **3.0** (the floor keeps the ratio finite when persistence is ≈ 0; 0.003 rad is the true-static tolerance and numerical-noise scale). The "true static" subset (geodesic < 0.003) uses the future truth and is reported as a **diagnostic subset** only.
3. Singular + tumbling windows: **full 3-D orientation** error = symmetric quaternion geodesic distance at K = 20 between composed predicted and true orientation; ratio to the best of {persistence, ridge if it has rotation outputs} ≤ 1.10 and bootstrap upper ≤ 1.25. Euler yaw is never used as ground truth at a singularity (tested: a D2-equivalent pose has zero orientation error although Euler yaw differs by π; garbage predictions on singular/tumbling windows do not change the yaw components).
4. Tilt: separate metric |sym-tilt error| from quaternions (unit-safe), reported only; if a stored tilt channel is supplied it must equal arccos(R22) within 1e-3 rad, otherwise the stored-channel metric is NOT_EVALUABLE (detects the radians/degrees mix of contract v1).
**Support**: every component needs ≥ 10 groups and ≥ 200 windows, otherwise NOT_EVALUABLE; a model with no orientation outputs is NOT_EVALUABLE with an explicit reason (yaw components accept either rotation vectors or legacy per-step yaw deltas; geodesic components need rotation vectors). Regime counts and errors per regime are reported.
Feasibility: v1 windows (I-1, development) carry no quaternions ⇒ **G7 is NOT_EVALUABLE on them by construction** (not a model result). S_in input-only support on v1 windows: I-1 7 810 windows / 50 groups; development 15 136 / 96. The persistence-yaw variant (P0, inference-only) would satisfy components 1–2 trivially (ratio 1, static error 0.0002 rad) but is NOT_EVALUABLE on component 3 until a model outputs rotation.
