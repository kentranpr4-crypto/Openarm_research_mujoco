## 1. G3 v3 (headroom-aware)
Per primary target (close on `test_id`; palm on the pooled low sets), reference = frozen outcome-only logistic, same at-risk windows as v2. `A_ref` = reference AUROC (pooled windows, cluster-by-group bootstrap as in v2).
- `A_ref ≤ 0.90` → margin branch (v2 rule): AUROC ≥ 0.80, CI lower ≥ 0.70, AUROC − A_ref ≥ 0.05.
- `A_ref > 0.90` → ceiling branch: AUROC ≥ 0.98 AND Brier skill ≥ 0.50. (CI of AUROC and of BSS are reported, not gating.)
- **Brier skill** = 1 − B_model / max(B_ref, floor); B = macro mean over initial-state groups of the per-group mean (p − y)²; floor = 1e-3 (flagged when used). Reference perfect-ish ⇒ the denominator is the floor, so BSS ≥ 0.5 requires B_model ≤ 5e-4.
- **Hard subset** (both branches): windows whose reference probability lies in [0.2, 0.8]; AUROC ≥ 0.90. Evaluable only with ≥ 10 groups having a positive window, ≥ 10 groups having a negative window, ≥ 30 positive and ≥ 30 negative windows; otherwise the condition is **NOT_EVALUABLE** (never PASS, never dropped). Gate verdict logic is v2: FAIL if any evaluable condition fails, else NOT_EVALUABLE if any is not evaluable, else PASS.
- Overall v2 sufficiency per target unchanged; insufficient ⇒ NOT_EVALUABLE.

## 2. G7 object orientation (yaw gated, tilt reported)
- θ_k = wrap(Σ_{j≤k} ΔYaw_j); error e_k = |wrap(θ̂_k − θ_k)| ∈ [0, π], horizons 1/5/10/20 reported, **K = 20 gating**.
- Gated windows = active windows without an **event** (any true per-step |Δyaw| > π/2 in the horizon: 80 % Euler-yaw singularity, 16 % physical tumble, 4 % ±π crossing — see the root-cause report). Event windows are reported separately (count, groups, errors) and the all-window ratio is reported next to the gated ratio. The event flag uses the future truth: a **diagnostic stratification, never an inference-time selection**.
- Primary: R = E_model / max(E_best, 1e-4 rad), E = macro mean over groups, E_best = min(E_persistence, E_ridge) (fixed on the point estimate); PASS iff R ≤ 1.10 and the group-bootstrap upper bound (97.5 %, 10 000 resamples) ≤ 1.25. NOT_EVALUABLE if < 10 groups or < 200 gated windows.
- Static hallucination (**input-only** subset S_in): box speed ≤ 0.005 m/s in all history rows, no finger contact and palm force ≤ 0.01 N in all history rows, candidate future gripper command stays open (≥ 0.028 m); gated mean e_20 over S_in (event windows excluded) ≤ 0.01 rad; NOT_EVALUABLE if S_in has < 10 groups or < 200 windows. The subset "true |θ_20| < 0.003 rad" is reported as a **diagnostic subset** (uses future truth).
- Tilt: reported only (|cumulative error| in channel units, `tilt_report`), no threshold, until a single-unit representation exists (contract defect: radians/degrees mix).

Findings that need your decision (no change made):
1. **Palm hard subset is structurally empty.** The outcome-only palm probabilities never reach [0.2, 0.8] (prevalence 1–3 %, frozen calibration), so with the rule as approved G3 can only return NOT_EVALUABLE or FAIL for the palm target — never PASS — in this data regime. More palm positives in I-2 would not change this unless the reference model is re-fitted at a higher prevalence. Options: (a) accept NOT_EVALUABLE for palm and gate G3 on close only; (b) apply the hard-subset rule only to targets with prevalence ≥ 5 %; (c) define the palm hard subset by the reference's upper quantile (e.g., top 5 %) instead of a fixed range.
2. **Absolute static threshold 0.01 rad is data-dependent:** even the ridge baseline gives 0.0084 on I-1's S_in but 0.0147 on development windows (it would fail there). Option: add a baseline-relative alternative (e.g., ≤ 2× the persistence error with floor) or keep 0.01 as a hard physical limit.
3. Interpretation choices I made: hard subset applies in **both** branches; margin branch keeps the v2 CI rule; ceiling branch is point-estimate gated; event windows excluded from gated means.
4. The event definition and S_in thresholds (0.005 m/s, 0.01 N) are physical-scale proposals, not tuned.
