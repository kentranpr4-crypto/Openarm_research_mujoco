# Yaw audit — why persistence beats the GRU on box yaw (post-hoc DIAGNOSTIC, no training)

Date: 2026-11-01. Inputs: frozen predictions of the independent evaluation (INDEPENDENT windows, already evaluated) and the development dry-run predictions (DEVELOPMENT windows). Code: `eval/yaw_audit.py`, `eval/oof_ridge_probe.py`; data: `outputs/yaw_audit/*.json` (not in git). No checkpoint, dataset, gate or official evaluator was changed. These are post-hoc, exploratory analyses; **nothing below was used to alter any result, and nothing can be claimed as a tested remedy.**
Independent results stay as reported: WM3-B yaw 0.0515 rad, persistence 0.0146 rad (K=20, 50 groups).

## 1. Verdict in one paragraph
The yaw deficit is **real, not a metric artifact**. Both GRU models add spurious rotation: on windows where the box truly does not rotate they still predict ~0.01 rad per step (≈0.06 rad at K=20), their yaw predictions have twice the variance of the truth and almost no correlation with it, and relative to a zero-rotation prediction their R² is strongly negative (WM3-B −4.1, C0 −2.2 on the clean subset). Yaw is almost unpredictable from the inputs (best learned model R² ≈ +0.07), so "predict no rotation" is near-optimal and any added variance hurts. A **probable contributor** (hypothesis, consistent with the data, not tested) is the loss: the yaw target's normaliser is dominated by 314 angular spikes in 1.69 M training deltas that carry 90 % of the squared-delta mass, so the yaw channel gives the network almost no pressure to suppress small spurious rotations.

## 3. Related observations
- `tilt` has the same normaliser issue (per-step delta std 0.60 rad; mean-zero spikes). Its R² on independent windows is strongly negative for all models (−9 … −23) but positive on development windows (0.08–0.35) — unstable, not gated; flagged, not investigated further.
- The gates (v1 and v2) contain no orientation criterion, so every PASS is blind to this failure.
- WM3-B is slightly worse than C0 on yaw (0.0515 vs 0.0460): the added ridge-forecast input did not help object orientation.

## 4. Mismatch probe for the ridge forecast (closed-form only)
K=20 joint error of the ridge forecast: in-sample train 0.00159, out-of-fold (5 group folds) 0.00164, val 0.00169, independent 0.00151 rad. OOF/in-sample = 1.036; normalised forecast RMSE 0.173 (in-sample) vs 0.179 (OOF) vs 0.185 (val). **The train/test mismatch of the ridge forecast is small (≈ 4–7 %)**, so it is unlikely to explain the yaw failure or to matter much for the box gain; out-of-fold forecasts are kept in the future design only as a sensitivity analysis.

## 5. What this does and does not establish
Supported (data): the deficit is an angular-prediction deficit of both GRUs, present from K=1, in all strata/phases/families, in both development and independent data; the wrap convention inflates the loss normaliser. Not established (hypotheses, need a controlled experiment that is not approved): that the loss normalisation is the cause; that a robust/angular loss, shrinkage or a relative-yaw representation would fix it. No shrinkage/oracle was fitted on the independent data.
